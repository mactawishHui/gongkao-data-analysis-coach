# 公考资料分析教练前向行为测试

测试日期：2026-08-30

测试方式：三个全新代理分别只收到技能路径和一段用户场景；它们独立读取技能，不继承实施讨论。持久化场景使用互不相同的测试数据库，速度场景只允许无状态公式与估算校验。

## 场景一：讲义勘误、高信心错误与真实记录

输入：第六讲 PDF p2 例 21；讲义和用户均选 B，用户用时 41 秒、表述“高信心”，并明确同意写入错题本。

结果：通过。

- 代理没有迎合讲义，比较 `33.4%>28.6%` 与 `8.9%>8.7%`，判定两种作物亩产均上升，正确选 C。
- 引用 `ERRATA-06-021`，把根因记为 `source_conflict`，并给出 15—25 秒的纯方向快法、失效边界、同类总结和迁移题。
- “高信心”按公开映射记为 `confidence=4`，没有擅自记成 5。
- `record` 实际回执：`ok=true`、`attempt_id=1`、`review_id=1`、`priority=high`、`next_review_date=2026-08-31`。
- `attempt 1` 回读：B/C、答错、41 秒、信心 4、主节点 `growth.ratio`、错误 `source_conflict` 与记录一致。
- 独立测试库：`.gongkao-study/forward-errata-v2.sqlite3`。文件名中的 `v2` 是首次前向测试留下的历史名称，不代表最终 schema；最终存储契约另见下方 v3 安全复验。

## 场景二：两题全对后的谨慎定位

输入：两道基期量题均答对，用时 55 秒、62 秒，均为一般信心、完整直除；用户明确同意记录并要求定位。

结果：通过。

- 两次写入均成功并完成 `attempt` 回读；“一般信心”记为 3。
- 因宽选项和常用分数仍使用完整直除，方法标为低效并安排次日方法复习，但没有把答对改判为答错。
- 节点 `abrx.base`：`2/2`、Wilson 90% 区间 `[0.4250, 1.0]`、状态“样本不足”。
- 用时中位数 58.5 秒，高于 45 秒目标；迁移和到期间隔复习均无证据。
- 图谱覆盖为 `1/41`，代理明确拒绝把样本内 100% 说成已掌握或整体水平。
- 下一步给出 6 道分层专项、20—30 秒常用分数目标和到期复习要求。
- 独立测试库：`.gongkao-study/forward-progress.sqlite3`。

## 场景三：45 秒增长量的人类快算

输入：现期 72414、同比增长 5.8%，选项 3788/3843/3970/4011；要求不做完整长除，说明方向、误差与失效条件，不授权记录。

结果：通过。

- 先算 `72414×5.8%≈4200`，把 `1.058` 放大为 `1.06`，用 `4000×1.06=4240` 反推估值约 3962；人类路径先于后台精算。
- 估值偏小；由 `3962×1.058=4191.796` 与真实分子 4200.012 的差，正向推出误差 `<9`，不是看见精确商后倒推误差界。
- `check-estimate` 回执：`bound_verified=true`、`safe=true`、选 C；向上边界 3990.5，决策余量 28.5，扣除误差后剩余 19.5。
- `calculate` 后台精确值为 `3969.7655954631377`，与快法选项一致；代理没有把精算冒充考场方法。
- 给出选项变密、分母截得更粗、负增长或接近 `-100%` 时失效的边界，并附迁移题。
- 用户未授权记录，代理未调用写库命令。根代理在场景结束后独立执行文件存在性检查，确认 `.gongkao-study/forward-speed-must-not-exist.sqlite3` 不存在。

## 安全加固复验

原三类前向测试验证教学行为；在 schema v3 安全加固后另做确定性复验：

- 全套自动化：237 项测试、449 个子用例全部通过。
- 新库初始化返回 `schema-v3`，并实际读回 `schema_meta.owner=gongkao-data-analysis-coach`、`version=3` 和 32 位小写十六进制 `instance_id`；已验证 Store 被另一结构合法的同类库替换后也拒绝写入。
- 在全新 v3 库记录第六讲例 21 后，`attempt`、`progress`、未来 `due` 三个只读查询前后主库 SHA-256 完全相同；单元测试同时逐字节比较主库与现有 sidecar 集合。
- 缺失数据库的只读命令不创建父目录或数据库；v2 只读不迁移；外来 SQLite、损坏结构、错误 owner 和未来版本在改动前拒绝。
- v2 旧默认 60 秒记录保留原始值并标 `legacy_unknown`，进度有效目标为 45 秒；15 条每题 50 秒的旧记录不再误报达速。
- 主库、`-wal`、`-shm`、`-journal` 均不能作为导出目标，即使指定 `--force`；普通 JSON 目标仍保持默认不覆盖。
- `.21±.09`、选项 `.2/.4` 的单向估算在恰触 `.30` 中点时判定不安全，剩余余量规范化为 0。
- 练习从题面可见十进制值独立复算并使用 `ROUND_HALF_UP`：`-7.135→-7.14`、`-14.375→-14.38`；隐藏题面有效数字的构造被拒。
- 10 个模板 × 3 档难度 × 每组 100 题，共 3,000 题逐题复算通过，每个 100 题题组内语义 ID 唯一。
- 根帮助和 `record --help` 均只输出一个 `ok=true` JSON；默认路径测试通过复制完整技能到临时工作区执行，未触碰真实默认学习库。

## 结论

三类教学前向场景与安全加固复验均满足技能契约：来源冲突不盲从、写入有真实回执、置信度不猜高、少样本不虚报掌握、快算有人类路径且误差可证、未授权不持久化；读取、迁移、导出和生成验证也遵守各自的副作用边界。
