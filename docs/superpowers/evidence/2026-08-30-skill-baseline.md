# 资料分析助手无技能基线

测试日期：2026-08-30

## 场景一：讲义答案与数学结论冲突

输入提供了玉米、稻谷亩产值与价格增速，讲义和用户均选择 B，并要求讲解及纳入学习记录。

普通助手的表现：

- 正确识别讲义答案有误，并用比值增长率验证正确答案为 C。
- 给出了“只判断升降时比较分子、分母增速”的快速规则。
- 在回复中列出了学习记录字段，但没有把记录写入任何持久化介质。
- 没有生成复习计划标识，也无法在后续会话中可靠检索这次高信心错误。

结论：单题推理合格；“已记录”与真实持久化状态脱节。

## 场景二：两题全对后要求准确定位

输入仅有 2 道基期量题，均正确，用时 55 秒和 62 秒。

普通助手的表现：

- 没有把样本内 100% 错当作真实掌握度，正确指出证据不足。
- 给出了继续扩样的合理建议。
- 没有提供可复算的置信区间、覆盖率、复发率或迁移题表现。
- 没有持久化两次作答，下一次无法基于同一证据更新定位。

结论：语言判断谨慎；缺少确定性统计和跨会话状态。

## 场景三：45 秒增长量快算

输入为现期 72414、同比增长 5.8%，选项 3788/3843/3970/4011。

普通助手的表现：

- 正确使用 `5.8/105.8≈5.5%`，判断估值偏大并向下修正到 C。
- 正确说明选项更密集时粗估会失效。
- 没有结构化记录“方法选择、估算方向、决策余量、方法质量”。
- 没有确定性验算接口，答案正确性仍依赖一次语言推理。

结论：快算行为值得保留；需要方法路由、误差账本与公式校验器。

## 技能必须弥补的失败模式

1. 只有回复中的“记录”，没有真实数据库写入与回读证据。
2. 单看正确率，缺少样本量、置信区间、速度、方法效率、迁移和复习保持度。
3. 快算策略依赖临场发挥，未形成按选项间距选择方法的稳定协议。
4. 计算结果缺少独立公式校验及讲义勘误优先级。
5. 单题解释与知识图谱、专项练习、下一次复习没有在获得明确授权后形成闭环。
