## 页码与抽取规则

1. 页数以原 PDF 文件结构核对，十讲依次为 `14, 16, 22, 23, 17, 15, 33, 20, 17, 27`；抽取文本中的 `PDF_PAGE_###` 标记与这些实际页数逐讲一一对应。
2. 页面内部印刷号不参与引用。尤其第二讲，实际 p1–p16 中的页内页号存在重复和错序；引用 `第二讲 p6` 只表示该 PDF 的第 6 个实际页面。
3. 公式、批注、手写图或复杂表格在纯文本抽取中可能缺字、乱序或乱码。若文本抽取与页面视觉冲突，以原 PDF 对应实际页的视觉内容为准，并在需要时用确定性公式独立复核。
4. 章节边界允许重叠，例如第四讲 p14 同时收束比值增长率并引入乘积增长率；重叠不是页码误差。
5. 来源页只证明该节点的知识依据，不代表可以忽略题目原始数据。快算结论仍须说明偏大/偏小、误差范围和选项安全边界；无法证明安全时升级精算。

## 引用格式

统一写作 `第 N 讲 PDF pX` 或 `第 N 讲 PDF pX–pY`。多处来源分别列出，不将页内印刷号换算成实际索引，也不根据章节连续性臆补空白页。
