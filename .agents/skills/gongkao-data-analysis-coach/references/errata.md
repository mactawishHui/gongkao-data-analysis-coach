## ERRATA-06-021

- **记录 ID**：ERRATA-06-021
- **讲次**：第六讲
- **PDF 实际页**：PDF p2
- **对象**：例 21 的最终答案
- **原文**：讲义给出答案 B，即“仅玉米亩产高于上年水平”。
- **更正**：答案应为 C，即玉米和稻谷亩产均高于上年水平。
- **判定依据**：亩产等于亩均产值除以单位价格。比值上升与否由分子、分母增速比较：玉米为 `33.4% > 28.6%`，稻谷为 `8.9% > 8.7%`。等价地，两项比值增长率 `(r产值-r价格)/(1+r价格)` 都为正，所以两种作物亩产均上升。
- **证据优先级**：P0（答案级）。数学恒等式和题目原始数据直接推出 C，高于讲义标答 B。
- **状态**：已确认；引用前按原 PDF 的实际 p2 做页面视觉定位，避免把页内印刷号当成 PDF 页码。

## ERRATA-06-029

- **记录 ID**：ERRATA-06-029
- **讲次**：第六讲
- **PDF 实际页**：PDF p9
- **对象**：例 29 解析步骤③；最终标答 A 本身正确。
- **原文**：步骤③在判断“比重下降且变化绝对值小于 2.4 个百分点”后写成“此处可选 B”。
- **更正**：步骤③应为“此处可选 A”；后续精算约下降 1.7–1.8 个百分点，也对应 A“下降不到 3 个百分点”。
- **判定依据**：现期比重约为 `2426.4/2948.2`。比重差公式为 `现期比重×(10.1%-12.5%)/(1+10.1%)`，结果约 `-1.8` 个百分点。负号表示下降，绝对值小于 3，只能选择 A。步骤③的 B 与其自身方向、范围判断以及后续精算均冲突。
- **证据优先级**：P1（解析标签级）。题目数据、数学恒等式和最终标答 A 相互一致，解析步骤中的单字母 B 优先被更正。
- **状态**：已确认；原 PDF 实际 p9 的答案区与解析区应做视觉交叉核对，文本抽取仅辅助检索。

## 使用与记录规则

1. 解答命中上述题目或同页解析时，先采用更正内容，并明确提示存在已确认来源冲突；不得照抄错误字母。
2. 若用户作答受到讲义冲突影响，记录根因代码 `source_conflict`，保留记录 ID、讲次、PDF 实际页、原文和更正。即使用户依靠独立计算答对，也可记录该来源风险，但不应把它计成用户知识错误。
3. 新冲突先标为待核验外部事项，不直接加入本表。必须回到原 PDF 实际页做视觉验证，并用题目原始数据或确定性公式独立复算；视觉内容与文本抽取冲突时，以页面视觉为准。
4. 快算只能辅助复核。若近似误差可能跨越选项边界，升级精算后再决定是否属于勘误，避免把不安全估算误报为来源错误。
