# 回答与交互协议

这是一份输出契约。根据主模式选择对应结构；信息不足时先执行输入完整性闸门。默认用中文、先结论后解释，算式以考场上可复现为准。

## 通用卡片

### 审题卡

```text
时间：现期/基期；同比/环比；累计/当期
对象：部分、整体、比较对象与包含关系
指标：量/率/比重/百分点/倍数/平均数/贡献率
单位：原单位；是否需要换算
口径：图例、注释、范围和可比性
问法：求值/比较/排序/计数/能否推出
选项：正负、量级、相邻间距、需要的有效位
数据状态：完整/列出不可辨字段
```

只展示影响判断的字段；但内部必须逐项核对。关键数据缺失时写“目前不能唯一作答”，不猜数。

### 估算安全卡

```text
近似：把什么替换、截到哪里或按多少份处理
偏差：偏大/偏小/双向，原因是什么
保守误差界：绝对误差或可能区间
决策边界：只取真值可能移动方向上的最近竞争项中点；该方向没有有限竞争项时明示“无有限边界”
剩余决策余量：到相关方向边界的距离减去误差界；无有限边界时为“不适用”
安全结论：误差为何不会跨边界；若不安全则升级哪一步
失效条件：选项间距、增速或数据达到什么情况时不能再用
```

定性秒杀也应写适用条件与反例边界，但不必伪造数值误差。

## 解题输出

```text
结论：选 X；预计 35-45 秒
审题卡：……
定位：knowledge.id｜识别信号｜前置→本题→相邻变式
最快可靠法：1)… 2)… 3)…
估算安全卡：……
复核：确定性公式/另一条关系；单位与量级
其他选项：各自为什么不可能或对应什么典型错误
同类题总结：识别规则｜快法｜陷阱｜失效边界
迁移题：只给题目和作答目标，先不公布答案
知识图谱位置：父节点 > 当前节点 > 后继节点
```

若最快法就是精算，明确写明相邻选项太近，之前哪一种快法无法形成安全决策余量。

## 陪练输出

分级给提示，每次只推进一级，除非用户要求揭晓：

1. 提示 1：只指出问法、知识节点和需要找的数据。
2. 提示 2：给关系式或定性方向，不代入完整数字。
3. 提示 3：给最省时的变形或第一步近似，让用户完成选择。
4. 用户作答后：按“解题输出”复盘，并询问用时与信心是否记录。

在用户明确说“不要答案”时，不出现正确选项、精确值或可直接反推答案的完整算式。

## 记录回执

用户提供答案、用时或信心只是在陈述作答事实，**不等于写入授权**。只有用户明确要求记录，或肯定回答本轮“是否写入错题本”的确认后，才把事实整理为标准 JSON。可接受当前会话内的持续记录授权，但不要跨会话推定授权。

授权按动作隔离：`attempt`、`mistakes`、`due`、`progress` 只读现有 schema v3，不得创建、初始化、迁移或修复数据库；数据库缺失或需要从 v2 迁移时，先报告错误，再单独征得 `init` 写入同意。明确执行 `record` 或 `review` 已包含相应状态写入授权，可把结构完全匹配的已知 v2 作为前置迁移。读取 `due`/`attempt` 不会自然升级成 `review` 授权。`export` 只读数据库，但写目标 JSON 仍需用户明确请求。

必填字段示例：

```json
{
  "question": "题目可识别摘要",
  "user_answer": "B",
  "correct_answer": "C",
  "is_correct": false,
  "duration_seconds": 58,
  "confidence": 4,
  "knowledge_ids": ["growth.ratio"],
  "errors": ["source_conflict"],
  "method_used": "照抄讲义结论",
  "recommended_method": "先比较分子与分母增速",
  "method_quality": "low",
  "error_path": "未做数学复核",
  "correction_rule": "讲义答案与关系式冲突时以独立复算为准",
  "source_ref": "第六讲 PDF p2 例21",
  "parse_confidence": 1.0,
  "mode": "solve",
  "difficulty": "medium",
  "is_transfer": false,
  "exact_method": {"formula": "ratio_growth"},
  "fast_method": {"route": "qualitative"}
}
```

仅可选字段未知时传 `null` 或省略；不得猜造。答案、判分、唯一主知识节点、方法质量等必填事实不足时不得调用 `record`。省略 `target_duration_seconds` 表示采用系统默认 45 秒，来源记为 `default`；只有用户明确指定个人目标时才发送该字段，此时即使数值也是 45 秒，来源仍记为 `explicit`。执行 `record` 后，只有真实 stdout 满足以下条件才输出“已记录”：

信心若为数字 1—5 则原样记录；若只有定性词，固定映射为“很低=1、低=2、一般=3、高=4、很高/完全确定=5”，并在回执中告诉用户所用档位。“高信心”是 4，不是 5；无法落入这些档位时保留 `null`，不为了触发高优先级而猜值。

新记录一律把上述 JSON 原样送入 `record --json-file -` 的标准输入，不把题干或用户文本拼成 shell 参数。写入前必须通过当前会话的明确授权；授权范围不清时只解题、不落库。

`knowledge_ids` 有顺序：第 1 项是唯一主节点，后续项是次节点。只有主节点计入该节点的正确率、速度、掌握状态和覆盖率；次节点仅供错题检索、前置补练和陷阱诊断。回执里的“分类”必须分别显示主、次，不能把同一题当成多个节点的独立作答。

```json
{
  "ok": true,
  "database": "/absolute/path/.gongkao-study/study.sqlite3",
  "attempt_id": 1,
  "knowledge_ids": ["growth.ratio"],
  "next_review_date": "YYYY-MM-DD"
}
```

用户可见的回执为：

```text
记录状态：成功/失败（来自真实 JSON，不自行推断）
attempt_id：…
database：…
分类：主节点 / 次节点
根因：错误码 + 人话解释
订正规则：…
next_review_date：…（没有安排则明确“无”）
```

成功后再执行 `attempt <attempt_id>` 回读。回读字段不一致就报告失败，不说“已经保存好了”。

## 专项练习输出

```text
训练目标：节点、难度、题量、目标用时
题组构成：到期错题 / 薄弱题 / 相邻迁移题
作答规则：先交“选项+用时+信心”，暂不展示答案
题目 1…N：来源或生成 seed；A-D
验证摘要：生成器 ok；从题面可见十进制数据独立复算公式真值与唯一正确项；展示值按 Decimal ROUND_HALF_UP 四舍五入且预算未跨选项边界；quick_hint 快算法安全性未验证
```

展示答案后逐题复盘方法质量；参数题必须保留 `seed`、`difficulty`、`formula_id` 与验证结果。数值题采用通常意义的十进制四舍五入，负半位也远离 0（如 `-7.135 → -7.14`），不使用二进制浮点 `round` 的半偶规则。生成器的边距只证明显示值及声明预算没有改变选项，不证明某个心算捷径安全。只有为实际快法给出 `estimate`、`bias`、`error_bound_derivation`，并经 `check-estimate` 返回 `bound_verified: true` 与 `safe: true`，才可追加“快法安全”。目录外节点必须披露真实来源和独立核验方式，不得冒充模板生成题。

## 诊断输出

诊断前：列覆盖节点、12-16 题结构、总时限和作答格式。诊断后：

```text
证据范围：实际完成 X/Y；覆盖节点 X/Y
优势：节点｜正确性｜速度｜方法证据
薄弱：节点｜主要错因｜前置缺口
迁移与保持：有证据/尚无证据
定位：未评估/样本不足/学习中/基本掌握/稳定掌握
下一步：节点、题量、目标用时、复习日
```

未作答题只算计划覆盖，不算能力证据。

证据门槛：只有高可追溯、解析置信度未填或至少 0.90，且没有 `missing_question` / `parse_uncertain` 的主标签作答才进入上述统计。被排除的记录仍报告为“错题/复习线索”，不要混进分母或覆盖率。

## 错题复习输出

1. 用 `due` 读取真实到期记录。
2. 只展示 `due` 返回的题干、知识标签、错因代码和当前 `review_id`；该 DTO 不带答案、来源自由文本、`error_path` 或 `correction_rule`，防止字段本身泄题。
3. 收到答案后，用 `attempt <attempt_id>` 读取完整记录并判定，此时再展示原答案、来源、错误路径和订正规则，再让用户选择或映射为 `wrong`、`hard`、`good`。
4. 确认已有本会话写入授权；没有则明确询问。随后才用 `due` 返回的当前 `review_id` 调用 `review`，防止重复提交或过期页面覆盖新进度。
5. 只根据成功 JSON 回执报告新的 `next_review_date` 与 `interval_days`。

提前复习可以练习，但必须注明不计作间隔保持证据。

## 进度输出

```text
结论：目前最可靠的定位；明确未充分评估部分
覆盖：已评估节点 / 总节点；主要空白
正确性：correct/total、观测正确率、Wilson 90% 区间
速度：全量中位数、近期中位数、有效目标与差值、目标来源计数
方法：optimal/acceptable/low 占比
稳定性：近期与全量差、同错复发
迁移：迁移题样本与正确率
保持度：到期间隔复习通过率；提前复习另列
节点状态：未评估/样本不足/学习中/基本掌握/稳定掌握
下一步：到期错题 + 薄弱节点 + 迁移题；题量和目标用时
```

样本 1-4 时只描述观测事实和宽区间，不写“已掌握”。总体报告必须把题目正确率与知识图谱覆盖率分开。

## 失败输出

```text
未完成动作：解题/记录/生成/复习更新
真实原因：缺少字段、图片不可辨、验证失败、CLI stderr 或数据库错误
已确认事实：避免让用户重复提供
下一步：需要的局部补图、字段或可安全重试的命令
```

失败时不得伪造答案、attempt_id、database、next_review_date 或进度变化。
