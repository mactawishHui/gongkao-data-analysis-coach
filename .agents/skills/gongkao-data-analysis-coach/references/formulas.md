# 资料分析公式、量纲与确定性复核

## 统一符号与输入口径

- `A` = 基期量，`B` = 现期量，`X` = 增长量，`R` = 增长率；基本关系是 `B=A+X=A×(1+R)`、`X=A×R`。
- 公式与核心函数内部的率统一用小数：`5%=0.05`，`-3%=-0.03`。CLI 输入可用 `rate_unit` 显式声明 `percent` 或 `decimal`，工具会在成功回执中统一归一为小数；展示为百分数时才乘 100。
- `%` 表示相对率；“百分点”表示两个百分数直接作差。脚本返回 `0.01` 的比重差时，展示为 `1` 个百分点，而不是 `0.01` 个百分点。
- 金额、人数、产量等加减前必须同单位；率、比重、倍数无量纲。题面数据按题面精度使用，不凭空补出更多有效数字。
- 讲义定位：ABRX 一般关系见第 1 讲 PDF 实际页 13–14 与第 2 讲页 2–3；基期、现期和增长量见第 3 讲页 2–21；增长率体系见第 4 讲页 1–23；现期、基期与隔级比重见第 5 讲页 2–17。

脚本复核不是考场方法。考场先按速度路由判断、估算或短算；只有答案边界过密、用户要求复核或讲义疑似冲突时，才把结构化数值交给脚本验证。脚本给出的浮点尾数也不得伪装成题面精度。

## ABRX 四量关系

### 基期量

- **公式 ID**：`base_period`
- **公式**：`A=B/(1+R)`。
- **量纲**：输出与 `B` 相同；`R` 无量纲，进入核心公式时必须已归一为小数（CLI 可接收明示的 `percent` 后代为换算）。
- **边界**：`R>-1`。`R=-1` 时分母为 0，不能由现期反推基期；`R<-1` 在通常数量语境下无意义。快判方向：正增长时 `A<B`，负增长时 `A>B`。
- **脚本函数映射**：`base_period(current=B, rate=R)`。
- **同类变式**：隔年基期 `A_{t-2}=B_t/[(1+r_t)(1+r_{t-1})]`，可先用 `interval_growth` 合成两率再调用 `base_period`；两对象基期差为 `B1/(1+r1)-B2/(1+r2)`；已知带符号变化量与同方向增长率且 `R≠0` 时，`A=X/R`。累计减当月必须把两项都还原到同一基期口径后再减。

### 增长量

- **公式 ID**：`growth_amount`
- **公式**：`X=B-A=A×R=B×R/(1+R)`，即“现期×r/(1+r)”。
- **量纲**：输出与 `A、B` 相同；正增长的 `X` 为正，下降的 `X` 为负。
- **边界**：`R>-1`。当 `B>0、R>0` 时，`0<X<B×R`，直接用 `B×R` 会偏大；当 `-1<R<0` 时不可沿用正增长的不等式和份数方向。
- **脚本函数映射**：`growth_amount(current=B, rate=R)`。
- **同类变式**：两项增量之比为 `[B1r1/(1+r1)]/[B2r2/(1+r2)]`，各增长量公式分母须合法且作为比值分母的第二项增量不得为 0；只有共同增长率 `r≠0` 时，比值才退化为 `B1/B2`。若总量在两期都严格等于若干互斥、完备、同单位分项之和，则差分保持线性：`X总=ΣX分项`，未知分项增量可用总增量减去其余带符号增量。比重、平均数、重叠集合不能直接套该加法。

### 现期、增长率与反代

- **公式 ID**：`abrx_general`、`current_period`、`growth_rate`
- **公式**：`B=A×(1+R)`；若 `A≠0`，`R=X/A=(B-A)/A`；若 `B-X≠0`，也可写 `R=X/(B-X)`。
- **量纲**：`A、B、X` 同量纲，`R` 无量纲。
- **边界**：率的分母必须非 0；“增长了 20%”是乘 `1.2`，“下降 20%”是乘 `0.8`，二者不能相互抵消为原值。固定增量预测 `B_n=B_0+nX`，固定增速预测 `B_n=B_0(1+R)^n`，二者不能混用；“首次超过”使用严格不等号并把解向上取到第一个满足的整数期。
- **脚本函数映射**：三者无独立函数；用 `base_period` 或 `growth_amount` 反代检查 `B=A+X=A×(1+R)`。图谱中的 `current_period` 指固定增量/固定增速的逐期预测关系，`growth_rate` 指 `X/A`。若给出的现期 `B名义` 按名义率形成，而问题要求同一基期按实际率计算，则 `B实际=B名义×(1+R实际)/(1+R名义)`；不能直接给 `B名义` 再乘一次实际率。

## 增长率体系

### 间隔增长率

- **公式 ID**：`interval_growth`
- **公式**：连续两段增长率为 `R=r1+r2+r1×r2=(1+r1)(1+r2)-1`。
- **量纲**：输入输出均为小数率；展示百分数时乘 100。
- **边界**：首段 `r1>-1`，否则中间量归零后下一段增长率通常无定义；末段允许 `r2=-1`，表示末期量归零，但不得小于 `-1`。不能漏交叉项：两率同号时交叉项为正，直接相加会偏小；一正一负时交叉项为负，直接相加会偏大。
- **脚本函数映射**：`interval_growth(r1, r2)`；练习模板的 `interval_growth_percentage` 仅把结果乘 100 后匹配百分数选项。

### 比值增长率

- **公式 ID**：`ratio_growth`
- **公式**：分子增长率为 `r_num`、分母增长率为 `r_den` 时，`R比值=(r_num-r_den)/(1+r_den)`。
- **量纲**：无量纲小数率。
- **边界**：分子率允许 `r_num=-1`，表示分子现期归零；不得小于 `-1`。分母率必须 `r_den>-1`，保证分母现期非零且 `1+r_den` 为正。比值上升/下降只看 `r_num-r_den` 的符号；不要颠倒两率。若两率都为正，直接用率差作结果通常只是一种有方向近似。
- **脚本函数映射**：`ratio_growth(num_rate=r_num, den_rate=r_den)`；`ratio_growth_percentage` 是练习展示适配 ID。

### 乘积增长率

- **公式 ID**：`product_growth`
- **公式**：若指标 `Z=P×Q`，则 `R_Z=r_P+r_Q+r_P×r_Q`。
- **量纲**：输入输出均为无量纲小数率；`Z` 的物理量纲由 `P×Q` 决定。
- **边界**：两个分率都可等于 `-1`，表示相应因子归零并使乘积增速为 `-100%`；任一率不得小于 `-1`。产量=面积×单产、总额=数量×单价等关系必须先验证口径；加法关系不能套乘积公式。
- **脚本函数映射**：`product_growth(r1=r_P, r2=r_Q)`。

## 比重体系

### 现期比重

- **公式 ID**：`current_share`
- **公式**：`s_B=现期部分B_p/现期整体B_w`。
- **量纲**：无量纲；脚本返回小数，显示百分比时乘 100。
- **边界**：整体 `B_w≠0`。只有“部分确属整体子集”时才必有 `0≤s_B≤1`；普通比值可能大于 1，不能机械当比重。
- **脚本函数映射**：`current_share(part=B_p, whole=B_w)`；`current_share_percentage` 是百分比展示适配 ID。

### 基期比重

- **公式 ID**：`base_share`
- **公式**：`s_A=(B_p/B_w)×(1+r_w)/(1+r_p)`，其中 `r_p` 为部分增速、`r_w` 为整体增速。
- **量纲**：无量纲小数比重。
- **边界**：`B_w≠0`，且 `r_p>-1、r_w>-1`。部分和整体增速不可反放。若 `r_p>r_w`，当前比重高于基期比重，因此修正因子 `(1+r_w)/(1+r_p)<1`。
- **脚本函数映射**：`base_share(part=B_p, whole=B_w, part_rate=r_p, whole_rate=r_w)`；`base_share_percentage` 用于百分比选项。

### 比重趋势、比重差与比值差

- **公式 ID**：`share_trend_direction`、`share_change`、`ratio_value_difference`
- **公式**：趋势由 `r_p-r_w` 的符号决定；`Δs=s_B-s_A=(B_p/B_w)×(r_p-r_w)/(1+r_p)`。普通比值绝对量变化同构，但不额外假定其落在 0—1。
- **量纲**：返回小数比重差；`Δs=0.014` 应展示为约 `1.4` 个百分点。
- **边界**：`B_w≠0、r_p>-1、r_w>-1`。在正的现期比重下，趋势符号由 `r_p-r_w` 决定。只有当 `(B_p/B_w)/(1+r_p)<1` 时，才可断言 `|Δs|<|r_p-r_w|`；不要把讲义中的常见秒杀条件扩张成无条件定理。
- **脚本函数映射**：`share_change(part=B_p, whole=B_w, part_rate=r_p, whole_rate=r_w)`；纯方向题用练习适配 ID `share_trend_direction`，比值绝对量变化用图谱关系 ID `ratio_value_difference` 并以两期原始比值反验。

### 隔级比重

- **公式 ID**：`multilevel_share`
- **公式**：若“小类⊂中类⊂整体”，则 `小类/整体=(小类/中类)×(中类/整体)`。
- **量纲**：无量纲；各层均用小数比重后相乘。
- **边界**：层级必须完全嵌套且同一时期、同一口径；若中间集合交叉或时期不同，乘法失效。
- **脚本函数映射**：无独立函数；两次 `current_share` 后相乘，并用原始小类/整体直除反验。

## 混合与十字交叉

### 加权混合与量比

- **公式 ID**：`weighted_average`、`cross_ratio`
- **公式**：两部分基期量为 `A1、A2`、对应率为 `r1、r2` 时，整体率 `r=(A1r1+A2r2)/(A1+A2)`；若 `r1<r<r2`，则 `A1/A2=(r2-r)/(r-r1)`。
- **量纲**：三个率使用同一小数口径；十字交叉输出基期量比，无量纲。
- **边界**：组成项须完备、互斥且同口径，整体率必须落在两端率之间；增长率混合的权重是基期量，不是现期量。多于两部分时先按题意合并为两组。
- **脚本函数映射**：当前无独立核心函数；用加权式与交叉式相互反代验证，不能把示意线段当作证据。

## 平均、年均与特殊考点

### 单个平均数、平均数变化与倍数

- **公式 ID**：`average_single`、`average_multiple`
- **公式**：`平均数=总量/个数`；平均数增长率仍套 `ratio_growth(总量增速, 个数增速)`，基期平均数可分别还原后相除。“是几倍”直接作比，“多几倍”在比值后减 1。
- **量纲**：总量单位/个数单位，例如“元/人”“吨/亩”；不能丢掉分母单位。
- **边界**：个数不得为 0；月均、日均须先确认覆盖月份、季度和闰年天数，累计期不能错除 12。
- **脚本函数映射**：单值平均无独立核心函数，由安全除法实现；增长率调用 `ratio_growth`，练习适配 ID 为 `average_single`。

### 年均增长量与年均增长率

- **公式 ID**：`average_annual_increase`、`average_annual_rate`
- **公式**：年均增长量 `=(末期量-基期量)/n`；年均增长率满足 `(1+r)^n=末期量/基期量`，即 `r=(末/基)^(1/n)-1`。
- **量纲**：年均增长量与原指标同单位/年；年均增长率无量纲。
- **边界**：`n` 是实际增长间隔数而非表中数据点个数。题干“2016—2020 年年均增加”若按五个同比增量口径，常需追到 2015 年基期；必须依题干和材料确认。开方公式通常要求基期、末期为正。
- **脚本函数映射**：无对应核心函数；练习适配 ID `average_annual_increase` 只处理已确认的起点、终点和间隔数。

### 增量贡献率

- **公式 ID**：`contribution_rate`
- **公式**：`贡献率=部分增量/整体增量`。
- **量纲**：无量纲小数率；展示百分数时乘 100。
- **边界**：整体增量不得为 0。贡献率可以为负，也可以超过 100%，不能按比重强行限制在 0%—100%。同一整体下比较各部分贡献率时：**整体增量为正**才与部分增量同序；**整体增量为负**时除以负数会翻转不等号，故与部分增量反序。
- **脚本函数映射**：`contribution_rate(part_delta, whole_delta)`；`contribution_rate_percentage` 是百分数展示适配 ID。

### 拉动增长与容斥

- **公式 ID**：`pull_growth`、`inclusion_exclusion`
- **公式**：`拉动增长=部分增量/整体基期量=贡献率×整体增长率`；两集合交集量满足 `max(0,A+B-T)≤A∩B≤min(A,B)`，比重形式为 `max(0,p_A+p_B-1)≤p交≤min(p_A,p_B)`。
- **量纲**：拉动增长是小数率，常展示为百分点；容斥量沿用总体单位，比重界无量纲。
- **边界**：拉动增长分母是整体基期量，不是整体现期量；容斥要求两个集合都在同一全集 `T` 中，且“至少/至多/都/任一”措辞必须逐字对应。
- **脚本函数映射**：拉动可先用 `base_period` 求整体基期后作除法，或用 `contribution_rate` 乘整体率；容斥无独立函数。

## 估算选项安全

- **公式 ID**：`assess_estimate_safety`
- **公式**：候选项按数值排序，相邻候选值的中点是选择边界。由估值 `e`、绝对误差上界 `E` 和偏差方向构造真值区间：未知方向为 `[e-E,e+E]`，估值偏大为 `[e-E,e]`，估值偏小为 `[e,e+E]`。区间严格不触碰边界才安全。
- **量纲**：`e、E、options` 必须使用完全相同的单位；决策余量和剩余余量也沿用该单位。
- **边界**：`E≥0`；至少两个且数值唯一的选项，当前实现最多 26 个。估值与多个选项等距，或误差区间恰好触及中点，都判为不安全。`bias="high"/"偏大"` 表示估值不小于真值；`bias="low"/"偏小"` 表示估值不大于真值。
- **脚本函数映射**：`assess_estimate_safety(estimate=e, absolute_error_bound=E, options=选项数值, bias=方向)`；单向偏差只返回真值可能移动方向上的最近竞争项和边界。若估值已在最外侧选项且误差只会继续向外，相关边界、余量和竞争项返回 `null`，表示该方向无有限边界且安全；不要把无关的另一侧几何近邻拿来比较 `E`。

## 出手前四项复核

1. 时期：问的是现期、基期、同比、环比还是跨期。
2. 口径：部分与整体、分子与分母是否同范围且同单位。
3. 方向：正增长/负增长、率差次序、近似偏大或偏小是否一致。
4. 边界：误差是否严格小于朝相关选项边界的决策余量；不能证明就升级计算，不输出虚假精度。
